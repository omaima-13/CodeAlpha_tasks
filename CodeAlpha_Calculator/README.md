# Basic Calculator

## Overview

This project is a simple calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division through an interactive user interface.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Clear button (AC)
* Delete button (DEL)
* User-friendly interface
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

Calculator/
│
├── index.html
├── style.css
└── script.js

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html` or open it in a web browser.
4. Use the calculator buttons to perform calculations.

## How It Works

* Users enter numbers using the calculator buttons.
* JavaScript handles user input and calculations.
* The result is displayed on the calculator screen.
